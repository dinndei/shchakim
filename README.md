# שחקים הפקות

אתר תדמית רספונסיבי בעברית עבור עסק להפקת אירועים, שנבנה עם Next.js App Router.

## הפעלה מקומית

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000).

## מבנה האתר

- `/` — דף הבית עם רשימת האירועים.
- `/events/[slug]` — עמוד גלריה לכל אירוע.
- `/contact` — פרטי יצירת קשר וטופס שפונה ליישום הדואר של המבקר.

## התאמה לעסק

- הלוגו נטען מתוך `public/assets/logo.png`.
- ערכו את רשימת האירועים, הטקסטים ותמונות ההדגמה ב־`data/events.ts`.
- החליפו את `hello@example.com` בכתובת העסק בטופס שב־`app/contact/page.tsx`. הטופס משתמש ב־`mailto:` ולכן דורש יישום דואר מוגדר אצל המבקר; לשליחת טפסים ישירה מהאתר יש לחבר שירות דוא״ל או API.
- תמונות הדוגמה נטענות מ־Unsplash. לפני פרסום מומלץ להחליף אותן בתמונות האירועים ובתוכן שבבעלות העסק.
