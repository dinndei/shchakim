# שחקים הפקות

אתר תדמית רספונסיבי בעברית עבור עסק להפקת אירועים, שנבנה עם Next.js App Router.

## הפעלה מקומית

```bash
npm install
npm run dev
```

פתחו את [http://localhost:3000](http://localhost:3000).

## מבנה האתר

- `/` — דף הבית עם רשימת האירועים.
- `/events/[slug]` — עמוד גלריה לכל אירוע.
- `/contact` — פרטי יצירת קשר וטופס ששולח פניות לכתובת העסק.

## התאמה לעסק

- הלוגו נטען מתוך `public/assets/logo.png`.
- ערכו את רשימת האירועים, הטקסטים ותמונות ההדגמה ב־`data/events.ts`.
- העתיקו את `.env.example` אל `.env.local` והגדירו את `RESEND_API_KEY`, את `RESEND_FROM_EMAIL` מדומיין שאומת ב־Resend, ואת `CONTACT_EMAIL` ככתובת שתקבל את הפניות. יש להשלים ב־Resend את רשומות ה־DNS לאימות הדומיין, כולל SPF ו־DKIM. המפתח נשאר בצד השרת ואינו נשלח לדפדפן.
- נקודת הקצה מגבילה כל כתובת IP לחמש פניות בכל 15 דקות ומכילה שדה honeypot לסינון ספאם. הגבלת הקצב נשמרת בזיכרון של תהליך Node.js; בפריסה מרובת מופעים או serverless יש להחליף אותה בפתרון מרכזי כגון Redis/Upstash או הגנת קצב של ספק הפריסה.
- כתובת המייל של הפונה מצורפת כ־`Reply-To`, כדי שאפשר יהיה להשיב ישירות להודעה שהתקבלה.
- תמונות הדוגמה נטענות מ־Unsplash. לפני פרסום מומלץ להחליף אותן בתמונות האירועים ובתוכן שבבעלות העסק.
